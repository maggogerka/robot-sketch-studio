ABOUT

Built for a pen,
not a plotter illusion.

Robot Sketch Studio traces the one-pixel skeleton of each mark into open SVG paths, then orders and reverses strokes to reduce pen-up travel. v0.1.0 controls only a simulated MockRobot; physical hardware adapters are deliberately disabled.
